# Student Management System

Simple full-stack Java project using Spring Boot, Thymeleaf, Spring Data JPA and MySQL.

Features: add, view, search, edit and delete students.

Tech: Java 17, Spring Boot, Spring MVC, Thymeleaf, JPA/Hibernate, MySQL, Maven, HTML5 and CSS3.

Run with `mvn spring-boot:run` and open `http://localhost:8080`.
